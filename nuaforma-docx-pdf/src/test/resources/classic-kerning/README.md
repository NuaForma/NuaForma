# Classic-kerning golden file

The synthetic Liberation Sans legacy case retains a genuine Word PDF export, its
source/PDF hash receipt, and an initially reviewed native 96-DPI page PNG. It covers
effective-size thresholds, inherited/direct settings, split runs, unchanged disabled
OpenType ligatures, Greek/Cyrillic and contextual classic kerning across spaces.
`SHA256SUMS` records all source/reference/golden bytes.

See the [formatting proof](../../../../../tools/pdf-evaluation/own-engine/FORMATTING.md)
for font provenance, differences and reproduction. Golden replacement requires a
reason, visual review and explicit approval. Tests write only candidates under the
ignored build directory.
