# Rich-text golden reference

`page-1.png` is the initial manually reviewed native 96-DPI PDFBox raster for `NativeRichTextTest`. Its builder is that test's synthetic `source`/RTF data, using the existing `own-engine/source.docx` fixture. It covers prefix/suffix joining, independent paragraph boundaries, bold/italic/underline/strike, explicit family/size/RGB, a real tab, Cyrillic and explicitly marked Hebrew RTL. A4 and Letter execute all four profiles; separate cases cover empty documents, long pagination and header/footer insertion.

The initial golden SHA-256 is `a57defe84fa840a70fc358361a259f315c520f4d4d043a11e736b3e2ee18bc1a`. Tests only write candidates under the module's ignored `build/118-rich-text`; they never create, refresh or overwrite golden resources. Changes to this resource require a specific explanation and explicit maintainer approval under the repository's golden policy.

The generated DOCX and independently authored expected WML were both exported by Microsoft Word 16.0 build 16.0.20527 through the existing read-only `export_word.ps1` helper. Their PDFs produced **identical pixels** at 96 DPI with the same PDFium renderer. Word comparison files/provenance are local qualification output, not test-time dependencies. The native raster was also visually reviewed alongside the Word export; different installed/font-resource versions and PDF rasterizers can produce small text-edge differences, so the native regression assertion uses this reviewed native image at zero tolerance.
