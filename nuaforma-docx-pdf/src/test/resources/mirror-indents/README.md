# Mirrored-indentation golden files

Five synthetic four-page A4/Letter cases retain genuine Word PDF exports, their
source/PDF hash receipts, and initially reviewed native 96-DPI page PNGs. Physical
page parity, restarted section display numbers, hanging/first-line indents,
ordinary paragraphs and modern/legacy compatibility switches are covered.
`SHA256SUMS` records all source/reference/golden bytes.

See the [formatting proof](../../../../../tools/pdf-evaluation/own-engine/FORMATTING.md)
for interpretation, font provenance, measured differences and reproduction.
Golden replacement requires a reason, visual review and explicit approval. Normal
tests never regenerate these files; candidates belong under the ignored build directory.
