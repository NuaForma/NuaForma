# Tabs inside numbered paragraphs

The development candidate admits typed tab controls within numbered and bulleted paragraph content. List markers keep their own label alignment and suffix; tabs in the following text use the existing paragraph tab stops and default interval. First-line and continuation indentation retain their separate meaning. The source restriction on mixed images and other unqualified list controls remains in force, as do the existing restrictions on underlined tabs, RTL lists, aligned list bodies and automatic table widths with tabs.

Sixteen inert Word controls exercise default and explicit left stops, right/center/decimal alignment, reached stops, wrapping and soft line breaks on A4 and Letter. The decimal controls use the document's declared comma separator. `python3 tools/pdf-evaluation/create_list_tab_fixtures.py <fresh-directory>` refuses an existing directory; its package parts reproduce byte-for-byte across the authoring environments. ZIP compression bytes can vary with the Python/zlib implementation. Original source archives and genuine Word export receipts remain the reference inputs.

Initial native golden images are authored only after independent content, geometry and visual review. Existing golden files remain protected. Native/profile and actual Playground qualification is recorded after those checks finish; a complete combined build is required before final delivery. Inline-list parsing uses existing model controls; the numeric policy below extends the shared API. Both remain in the existing packages and dependencies. These source changes do not publish a release or change Playground controls.

## Numeric decimal alignment

`PdfTabSettings.withDecimalPolicy(PdfDecimalTabPolicy.FIRST_NUMBER, groupingSeparator)` adds a neutral numeric-field rule. Existing constructors retain the original explicit-separator rule. Numeric alignment finds a leading decimal separator or the end of the first numeric sequence, ignoring the configured grouping separator. The following text, font sizes, kerning, letter spacing and physical advances remain unchanged. The measured prefix spans keep their individual styles. No host locale is consulted by the shared engine.

The DOCX adapter selects the numeric rule using its existing declared decimal-symbol interpretation (period when absent) and the opposite comma/period grouping character. Genuine Word controls record the reference application's decimal and grouping settings explicitly; Word's regional settings can affect tab alignment. See [Microsoft's tab interpretation](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/5c5c4a0a-02ba-44d7-a0f2-c101221ce4a8) and [regional decimal settings](https://support.microsoft.com/en-us/word/use-decimal-tabs-to-line-up-numbers-with-decimal-points).

`python3 tools/pdf-evaluation/create_decimal_tab_fixtures.py <fresh-directory>` builds 44 additional single-item A4/Letter sources for amounts, currency prefixes, grouping, units, mixed text/numbers, signs, parentheses and leading separators. The source archives use stored ZIP entries for byte-exact cross-environment reproduction. Their Word PDFs and original-source receipts retain the actual locale. All 60 list/numeric Word/native page pairs passed independent complete-content, paper and marker-geometry checks and visual review before initial native PNG references were authored. The largest measured marker difference is 0.178 point horizontally and 0.059 point vertically. The maintained regression matrix covers 84 standard/PDF-A profile PDFs with exact native reference pixels and no masks. The 84 golden/profile PDFs pass with no masks or pixel tolerance. Actual Playground requests produced 136 PDFs across standard PDF and PDF/A-1b/2b/3b, retaining complete Word content/paper and exact native provider pixels. The 250-document run retained all previous 21 successful documents and 59 pixel-identical pages. Source Sans Pro was supplied only in the local test setup. The complete combined normal build also passes.
