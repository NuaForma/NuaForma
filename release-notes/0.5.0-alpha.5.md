# NuaForma 0.5.0-alpha.5

This evaluation alpha broadens native DOCX-to-PDF layout and updates the bundled AMD64 Java runtimes.

- Tab fields follow Word when data changes text length or an aligned stop reaches the right margin. A fixed table with an automatic zero width keeps its declared grid when the physical cell widths agree.
- The qualified profile preserves solid run and paragraph backgrounds, tight automatic spacing, horizontal text scaling and explicit page breaks, including breaks within numbered paragraphs.
- Inline picture extents, clipping and floating drawing order are retained in the qualified layouts. Supported fixed and automatic tables retain their horizontal alignment.

[Layout PR #312](https://github.com/NuaForma/NuaForma/pull/312) passed Java 17/25, native AMD64/ARM64 and the Sonar Quality Gate. The normal local build passed 1,957 JVM tests. The unchanged local corpus produced 23 of 250 PDFs. The last iteration kept all 64 prior PDF pages pixel-identical and converted one additional two-page document. Separate genuine Word exports establish bounded fidelity for the layout controls. Some paragraph wraps still differ, and floating VML shape groups are outside the qualified profile. Private corpus data and fonts stay local.

The shared PDF model adds neutral layout controls in the existing library. Exhaustive Kotlin handling of `PdfInline` must account for the new `PdfPageBreak` variant. The Java compatibility boundaries, PDF profile options and resource limits are unchanged. Java 17 libraries and validators remain separate from the Java 25 applications.

[Runtime PR #313](https://github.com/NuaForma/NuaForma/pull/313) selects signed Temurin 17.0.21.1+2 and 25.0.5.1+2 for AMD64 to address CVE-2026-114938. The retained ARM64 runtimes are outside the affected x86-64 code path. The candidate audit tracks remaining native runtime findings under #51. [Adoptium advisory](https://adoptium.net/news/2026/11/temurin-november-2026-cspu-java4shell/)

Six libraries are prepared for Nexus prereleases and two multiarch container indexes are prepared for GHCR. Standard PDF and PDF/A-1b/2b/3b retain font embedding and independent validation. PDF/A-1b still rejects requested watermarks. This prerelease leaves Central and `latest` unchanged.
