# NuaForma 0.4.0-alpha.5

This evaluation alpha preserves Word style revision metadata and makes unsupported image content easier to diagnose and clean.

- Retain validated style-level `w:rsid` editing metadata in the original template, ignoring it only in the request-local rendering view. Invalid values, duplicates and foreign/nested content remain explicit failures.
- Identify the exact rejected image element/first child (for example `effectLst/outerShdw`) or attribute (`xfrm/@rot`), with actual source coordinates in the named body/header/footer part. New explanations omit attribute values; production source-detail redaction remains unchanged.
- Playground cleanup removes the focused unsupported effect/optional attribute where possible instead of dropping the whole logo or surrounding story. Unsupported effectExtent is removed as a complete optional element so required attributes cannot be left absent.
- Normal PDF generation remains strict and emits no partial output for unsupported input. Cleanup can change appearance; review the report and copied DOCX. No new visual effect/geometry support or external template/image retrieval is introduced.

The complete local WSL build passed 1,182 tests. Synthetic A4/Letter metadata and focused body/footer cleanup cases remain pixel-identical to the supported baseline using image-comparison with zero tolerance. Existing goldens and authored resource files are unchanged. The actual unavailable private document/effects are not covered by this bounded proof. See the [cleanup guide](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.5/docs/template-cleanup.md).

Full Java 17/25, native AMD64/ARM64 and actual Sonar qualification passed on the source change (Quality Gate OK, 83.0% new-code coverage). Release preparation reuses identical-input qualification. Standard PDF and PDF/A-1b/2b/3b retain their existing embedded-font and independent validation policies; earlier image transparency limits remain unchanged.

## Downloads and evaluation scope

All six libraries publish to [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/). Production and development-only Playground images provide native AMD64 and ARM64. Prereleases leave `latest` unchanged; no Maven Central publication is involved. No LibreOffice, Word or cloud conversion service is required at runtime. ODT remains future work.

Runtime inputs retain Temurin 17.0.21+9 validators, Temurin 25.0.5+8 applications and pinned 2026-10-30 Debian packages. Unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed release tag supplies NuaForma source.

Residual findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The protected final review must accept them for **0.4.0-alpha.5 only**; earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.5/docs/release-0.4.0-alpha.5-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
