# NuaForma 0.3.0-alpha.5

Word runs formatted as hidden in print view no longer activate template instructions. Hidden text, including inherited hidden styles, no longer causes invisible marker errors; diagnostic locations remain anchored to visible source runs.

Insert bounded RTF data with `{description | richText("rtf")}`. Bold, italic, underline, strike, Unicode, explicit fonts/colors and paragraph fragments are supported within the documented profile. Empty boundary paragraphs are trimmed independently by default, and insertion is inline by default. Unsupported/active RTF fails explicitly; inserted text is not evaluated again as template syntax. See the [rich-text guide](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.5/docs/rich-text.md) for placement, budgets, font policy and errors.

Validated passive bibliography metadata is retained for DOCX generation and admitted by the PDF reader without changing page layout. Other unsupported custom XML remains rejected. This does not add citation-field evaluation or general custom-XML support.

Contract 0.7 adds optional content metadata with compatible defaults. Keep all six libraries aligned. `PdfTextStyle` retains the tested existing constructor/copy/destructuring JVM descriptors, but it is no longer a Kotlin data class: reflection-based `isData` inspection changes. Review the rich-text compatibility notes when upgrading extensions. Java 17 remains the embedded-library baseline; Java 25 runs the standalone server and development Playground.

## Downloads and development channels

- Six `dev.nuaforma` libraries: **0.3.0-alpha.5**, from the public [Nexus prerelease repository](https://repo.nuaforma.dev/repository/nuaforma-prereleases/).
- Production: `ghcr.io/nuaforma/nuaforma:0.3.0-alpha.5`.
- Development Playground: `ghcr.io/nuaforma/nuaforma-playground:0.3.0-alpha.5`.
- Both container indexes contain native Linux AMD64/ARM64. Prereleases leave `latest` unchanged.
- `0.3.0-SNAPSHOT` is on the separate public Nexus snapshot repository; subsequent green develop pushes publish a new signed timestamped generation after Java 17/25 and actual Sonar analysis/Quality Gate succeed.
- Only stable releases publish to Maven Central. Existing Central versions remain available. See the [repository guide](https://nuaforma.dev/repositories.html) for Maven/Gradle configuration.

The full Java/native CI supplies qualification. Release preparation reuses it and builds the six signed libraries and four images once; it does not repeat per-container generation/visual/load tests. The single protected final approval binds the exact candidate, reviewed source materials and runtime-risk disposition to publication and matching website delivery. Golden files remain unchanged.

## Updated runtime and source materials

The images use official unmodified Temurin **17.0.21+9** for independent validators and **25.0.5+8** for server/Playground, plus the reviewed 2026-10-30 Debian package snapshot and compatible library updates. Named Expat findings are fixed by the selected vendor package; previously published images remain unchanged.

Matching Debian, both-JVM/build-provenance and third-party JVM source/notice bundles are published separately under [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5). That source-only tag contains no product binaries or container release. It is not an additional Maven version. The signed `v0.3.0-alpha.5` tag provides the NuaForma engine/service source; candidate and publication receipts bind the exact artifacts and source hashes.

Residual native-runtime findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51), including the separately bundled FreeType copies. This evaluation release requires explicit acceptance of the current candidate's findings in the final approval; historical alpha acceptances are not reused. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.5/docs/release-0.3.0-alpha.5-audit.md). No zero-vulnerability or general production-safety claim is made.
