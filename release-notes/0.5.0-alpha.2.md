# NuaForma 0.5.0-alpha.2

This evaluation alpha makes missing-font failures actionable in the development Playground.

- Missing font diagnostics identify the requested family and variant, for example `Missing font family: Calibri; variant: boldItalic`.
- Variants are `regular`, `bold`, `italic` and `boldItalic`. The existing Cause line and correlated development logs display the details.
- Mapped reader failures retain the DOCX part, paragraph and XML location. Unavailable coordinates are omitted rather than invented.
- Font names are bounded and sanitized. Production responses and logs retain restricted diagnostics. Font selection, synthetic-bold fallback and normal conversion behavior are unchanged.

The change was delivered through [PR #302](https://github.com/NuaForma/NuaForma/pull/302). Seventeen focused JVM tests, existing Playground JavaScript tests and actual standalone production/Playground HTTP probes passed. Both real HTTP controls produced independently validated PDFs. Full Java 17/25 and native AMD64/ARM64 qualification passed; actual SonarCloud analysis passed with 87.2% new coverage. No public API, dependencies or golden files changed.

All six libraries use [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/). Production and development-only Playground images retain native AMD64/ARM64. Java 17 libraries/validators and Java 25 applications retain their existing boundaries. Standard PDF and PDF/A-1b/2b/3b retain embedding and independent validation; PDF/A-1b rejects requested watermarks. No Maven Central publication or `latest` update is requested. See the [diagnostic guide](https://github.com/NuaForma/NuaForma/blob/v0.5.0-alpha.2/docs/template-diagnostic-pdf.md).

Runtime pins and corresponding-source baseline remain unchanged: Temurin 17.0.21+9 validators, Temurin 25.0.5+8 applications, authenticated Debian snapshot 20261030T000000Z and [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5). The single protected final review must accept the documented residual [#51](https://github.com/NuaForma/NuaForma/issues/51) findings for this evaluation alpha only; earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.5.0-alpha.2/docs/release-0.5.0-alpha.2-audit.md). ODT remains future work; arbitrary DOCX fidelity is not promised.
