# NuaForma 0.4.0-alpha.6

This evaluation alpha preserves more Word logos and keeps Playground cleanup downloads beside their control.

- Preserve validated picture editing locks, explicit no-fill/no-line formatting and the canonical local-DPI BLIP extension in supported templates. Unknown extensions, visible strokes and invalid metadata remain explicit failures.
- Classify EMF headers using their description-buffer offsets. Long classic UTF-16 descriptions no longer masquerade as OpenGL/pixel fields. Actual OpenGL, pixel-format descriptors, unsafe records and malformed bounds remain unsupported.
- Show cleanup progress, errors and the ZIP download inside the Playground cleanup block. Selecting another template invalidates old links and late responses; ordinary generation downloads remain independent.

The full local WSL build passed 1,189 JVM tests; all 19 Playground JavaScript tests passed. Public synthetic A4/Letter fixtures cover large body/header-position logos and smaller footer logos, unchanged cleanup bytes and zero-tolerance PDF image comparisons. Existing goldens are unchanged. These tests do not qualify the unavailable private original or promise support for every EMF. See the [picture/header profile](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.6/docs/word-picture-metadata.md).

Java 17/25, native AMD64/ARM64 and actual SonarCloud Code Analysis passed on the source change (Quality Gate OK, 90.7% new-code coverage). Release preparation reuses identical-input qualification. Standard PDF and PDF/A-1b/2b/3b retain existing font embedding and independent validation. No checkbox pipe (#149) is included.

## Downloads and evaluation scope

All six libraries publish to [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/). Production and development-only Playground images provide native AMD64 and ARM64. Prereleases leave `latest` unchanged; nothing publishes to Maven Central. No LibreOffice, Word or cloud conversion service is required at runtime. ODT remains future work.

Runtime inputs retain Temurin 17.0.21+9 validators, Temurin 25.0.5+8 applications and pinned 2026-10-30 Debian packages. Matching unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed release tag provides NuaForma source.

Residual findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The protected final review must accept them for **0.4.0-alpha.6 only**; previous approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.6/docs/release-0.4.0-alpha.6-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
