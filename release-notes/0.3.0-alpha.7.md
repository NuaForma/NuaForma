# NuaForma 0.3.0-alpha.7

Passive Word bookmarks, spelling/grammar proofing markers and cached page hints no longer split qualified visible expressions or cause false missing-closing-brace failures. This includes cached hints inside mixed runs with tabs or real breaks. Formatting, bookmark identities/order and actual semantic boundaries remain protected. Cached hints stay on surviving runs; stale hints are discarded when no content remains.

The development preview now marks only the first actual parser failure with `[ERROR 1]`, directly at its source position, and appends its reason, logical DOCX part, paragraph and bounded excerpt/position. Other malformed fragments stay literal; conservative control regions use `[LITERAL BLOCK]`. Ordinary generation stays strict and production retains restricted diagnostics. See the [diagnostic guide](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.7/docs/template-diagnostic-pdf.md) and [DOCX profile](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.7/nuaforma-docx/README.md#word-template-rules).

Qualification includes 1,042 tests, real HTTP diagnostics, exact PDF text/page parity and zero-tolerance pixel comparison. Existing golden files remain unchanged. Java 17/25 and native AMD64/ARM64 pass; the real Sonar Quality Gate passes with 94.8% new-code coverage. Contract 0.8 and all six aligned libraries remain unchanged.

## Downloads and evaluation scope

The six alpha libraries use [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/); stable releases use Maven Central. Production and development Playground images provide native AMD64 and ARM64. Prereleases leave `latest` unchanged.

Dependencies/runtime inputs remain unchanged: official Temurin 17.0.21+9 validators, Temurin 25.0.5+8 service/Playground and pinned 2026-10-30 Debian packages. The matching unchanged third-party source/notice archives remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); signed `v0.3.0-alpha.7` supplies NuaForma source. Preparation verifies their public identities without redownloading the archives.

Remaining native-runtime findings stay open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The single protected final approval must explicitly accept the retained findings for this evaluation alpha.7 only. Earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.7/docs/release-0.3.0-alpha.7-audit.md). No general production-safety or zero-vulnerability claim is made.
