# NuaForma 0.4.0-alpha.4

This evaluation alpha retains more Word logos and footer content through Playground cleanup and PDF conversion.

- Support bounded unwrapped floating header/footer images and text frames, retaining surrounding text, relationships and footnotes. Repeated frame page fields resolve on each page.
- Accept validated zero-valued Word relative-size placeholders while retaining explicit image dimensions. Unsupported anchor children now identify the actual rejected construct.
- Preserve valid nonprinting paragraph-mark highlight without highlighting unrelated text. Colored numbered-paragraph marks remain outside the qualified profile.
- Keep floating header artwork behind body text without reserving extra body space. Reject body art overlapping reserved footnotes without publishing a partial PDF.
- Passive attached-template references may still be detached during cleanup; external targets are never fetched. Structural cleanup does not guarantee fonts, template syntax/data or final layout.

Synthetic A4/Letter/frame cases match real Word exports across six visually reviewed pages: matching normalized text and position-sorted words, maximum word-box top difference 0.699 pt (about 0.25 mm). Existing golden files and tolerances are unchanged. This is bounded qualification, not universal DOCX or pixel-perfect support. See the [floating-band qualification](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.4/tools/pdf-evaluation/own-engine/WORD_FLOATING_BANDS.md).

Standard PDF and PDF/A-1b/2b/3b remain supported with embedded caller-supplied fonts and existing independent validation. The new transparent-image fixtures pass veraPDF for 2b/3b and remain explicitly refused for 1b. Full Java 17/25, native AMD64/ARM64 and actual Sonar qualification passed on the source change; preparation reuses identical-input evidence.

## Downloads and evaluation scope

All six libraries publish to [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/). Production and development-only Playground images provide native AMD64 and ARM64; prereleases leave `latest` unchanged. No Maven Central publication, LibreOffice or runtime Word service is involved. ODT remains future work.

Runtime inputs retain Temurin 17.0.21+9 validators, Temurin 25.0.5+8 applications and pinned 2026-10-30 Debian packages. Unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed release tag supplies NuaForma source.

Residual findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The protected final review must accept them for **0.4.0-alpha.4 only**; earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.4/docs/release-0.4.0-alpha.4-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
