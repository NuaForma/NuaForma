# NuaForma 0.4.0-alpha.3

This evaluation alpha retains more ordinary Word formatting and logos without cleaning away supported content.

- Preserve paragraph-mark line metrics, signed physical-page indents, hanging indents and qualified linked-style/editor metadata.
- Reserve measured header/footer space, including a large header logo, smaller footer logo and real footnotes, rather than removing a whole band because its offset exceeds the original margin.
- Render a bounded, validated EMF GDI subset at 288 dpi using request-local state and explicitly supplied physical font bytes. No dependencies, modules or external document-renderer fallback were added.
- Fully opaque supported EMF images work in PDF/A-1b. Actual transparency is rejected explicitly for 1b; standard PDF and PDF/A-2b/3b retain their validation policies. Unknown records, EMF+ and unsafe constructs remain unsupported.
- Playground cleanup retains these supported constructs and removes only affected unsupported image references; ordinary generation remains strict.

Synthetic A4 and Letter documents each retain two pages and identical position-sorted words per page against real Word exports. Header/footer logos and footnotes remain present. Four comparison pages were visually reviewed; the maximum word-box top difference is 0.649 pt (about 0.23 mm). This is a bounded profile, not a universal DOCX/EMF or pixel-perfect claim. The private original was unavailable; no private template or existing golden was changed or uploaded. See the [compatibility profile](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.3/tools/pdf-evaluation/own-engine/WORD_COMPATIBILITY.md).

Full Java 17/25 and native AMD64/ARM64 qualification pass, with the actual Sonar Quality Gate OK and 83.8% new-code coverage. Release preparation reuses those matching results rather than repeating the suite.

## Downloads and evaluation scope

All six libraries use [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/); stable versions use Maven Central. Production and development Playground containers provide native AMD64 and ARM64. Prereleases leave `latest` unchanged. No LibreOffice, Word or cloud service is required at runtime. ODT remains future work.

Runtime inputs retain official Temurin 17.0.21+9 validators, Temurin 25.0.5+8 service/Playground and pinned 2026-10-30 Debian packages. Unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed v0.4.0-alpha.3 tag supplies NuaForma source. Preparation verifies public source identities without downloading large archives again.

Residual runtime findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The single protected final review must accept them for **0.4.0-alpha.3 only**; earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.3/docs/release-0.4.0-alpha.3-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
