# NuaForma 0.4.0-alpha.1

This minor evaluation alpha expands qualified Word compatibility and effective formatting while retaining contract 0.8 and the six aligned libraries.

- Passive package properties, font-table/web settings and bounded Word compatibility settings are accepted without fetching external resources or silently dropping effective formatting.
- Automatic paragraph spacing, physical-page mirrored indentation and conditional table formatting now follow the qualified Word policies.
- Requested kerning and standard OpenType ligatures use caller-supplied font outlines while preserving logical Unicode text and permission-checked subset/full embedding for standard PDF and PDF/A-1b, 2b and 3b.
- The development Playground uses the NuaForma favicon and retains precise source inspection and first-error previews. Ordinary generation remains strict.

The [formatting qualification](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.1/tools/pdf-evaluation/own-engine/FORMATTING.md) records 33 synthetic DOCX cases and 60 genuine Word-reference pages, bounded differences and unsupported combinations. Java 17/25, five consumers, both native architectures and the actual Sonar Quality Gate pass; new-code coverage is 88.8%. Existing golden files remain unchanged. This is a bounded native profile, not a promise to reproduce every Word construct.

Supply licensed fonts referenced by the document, even if its visible text is empty. Missing faces fail explicitly rather than being substituted. The test-only font fixture is not bundled with production libraries or images.

## Downloads and evaluation scope

The six alpha libraries use [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/); stable versions use Maven Central. Both production and development Playground images provide native AMD64 and ARM64. Prereleases leave `latest` unchanged. No LibreOffice, Word or cloud service is required at runtime; ODT remains future work.

Runtime inputs retain official Temurin 17.0.21+9 validators, Temurin 25.0.5+8 service/Playground and pinned 2026-10-30 Debian packages. Unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed v0.4.0-alpha.1 tag supplies NuaForma source. Preparation checks these published identities without downloading the source archives again.

Residual runtime findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The single protected final review must accept them for **0.4.0-alpha.1 only**; earlier approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.1/docs/release-0.4.0-alpha.1-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
