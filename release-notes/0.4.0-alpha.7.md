# NuaForma 0.4.0-alpha.7

This evaluation alpha retains otherwise supported EMF logos whose unused header descriptions lack a final UTF-16 zero.

- Treat bounded description text as opaque metadata in both normal PDF generation and Playground cleanup. Do not decode, log, evaluate or scan the text for a terminator; preserve original DOCX/EMF bytes.
- Keep declared-count/range limits and fixed-header classification. Invalid offsets/counts, out-of-record spans, actual OpenGL/pixel descriptors, unsafe records and resource overruns remain explicit failures. This is a bounded compatibility exception to description syntax, not general malformed-EMF support.
- Regress both large body/header-position and smaller footer logos on A4 and Letter. Cleanup preserves their relationships and notes and leaves supported template bytes unchanged; generated PDF pages remain pixel-identical to the supported baseline.

The full local build passed 1,193 JVM tests with no failures or skips. All 38 targeted EMF/floating-story tests passed; both new positive regressions first reproduced the alpha.6 rejection. Existing golden images and authored fixtures are unchanged. The private original was unavailable; these results qualify public synthetic variants, not every possible EMF. See the [compatibility policy](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.7/docs/word-picture-metadata.md).

Java 17/25, native AMD64/ARM64 and actual SonarCloud Code Analysis passed on the source change (Quality Gate OK). Release preparation reuses identical-input qualification. Standard PDF and PDF/A-1b/2b/3b retain existing embedded-font and independent validation policies. No checkbox pipe (#149) is included.

## Downloads and evaluation scope

All six libraries publish to [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/). Production and development-only Playground images provide native AMD64 and ARM64. Prereleases leave `latest` unchanged; nothing publishes to Maven Central. No LibreOffice, Word or cloud conversion service is required at runtime. ODT remains future work.

Runtime inputs retain Temurin 17.0.21+9 validators, Temurin 25.0.5+8 applications and pinned 2026-10-30 Debian packages. Matching unchanged third-party sources/notices remain at [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed release tag provides NuaForma source.

Residual findings remain open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The protected final review must accept them for **0.4.0-alpha.7 only**; previous approvals do not transfer. See the [candidate audit](https://github.com/NuaForma/NuaForma/blob/v0.4.0-alpha.7/docs/release-0.4.0-alpha.7-audit.md). This evaluation release makes no general production-safety or zero-vulnerability claim.
