# NuaForma 0.5.0-alpha.6

This evaluation alpha expands native DOCX-to-PDF support for Word documents.

- More qualified table grids, merged cells, margins, borders, shading and row layout are preserved.
- The renderer handles more aligned tabs, paragraph spacing, line breaks, links and bookmark ranges. Supported Word fields retain their visible text and page references.
- More pictures, including supported SVG artwork, retain their position and dimensions. The qualified profile also covers more floating drawings and text frames in page bands.
- The Playground reports more precise source and layout failures. PDF and PDF/A conversion continue to use the shared native renderer.

The corpus evaluation produced 68 PDFs from 250 unchanged local documents. The last qualified iteration preserved the text and pixels of 320 previously successful pages. Two additional documents also passed independent PDF/A-3b validation. Word references and regression fixtures describe the qualified cases. Public compatibility remains bounded by the [native profile](nuaforma-docx-pdf/README.md).

CI runs the complete test suite once with coverage and Sonar. Separate Java 17 consumer and AMD64/ARM64 container checks cover the embedded libraries and shipped images. See [PR #316](https://github.com/NuaForma/NuaForma/pull/316) and the [candidate audit](docs/release-0.5.0-alpha.6-audit.md).

The six signed libraries are prepared for Nexus prereleases. Both multiarch container images are prepared for GHCR. The selected runtime and remaining [#51 findings](https://github.com/NuaForma/NuaForma/issues/51) are covered by the candidate review.
