# NuaForma 0.3.0-alpha.6

Render qualified Word paragraph borders and passive VML/DrawingML lines instead of rejecting these documents. Solid, dashed, dotted and double strokes retain their supported colors, widths and positions. Inherited rules, connected paragraph frames, table-cell fills, page bands and pagination are qualified against genuine Word exports. Four new protected golden images guard the supported layout; existing references remain unchanged. See the [line profile](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.6/tools/pdf-evaluation/own-engine/LINES.md) for unsupported effects and combinations.

Development diagnostics retain concrete native rejection explanations and identify the source part, paragraph, XML path and a redacted excerpt. The Playground offers a marked DOCX inspection copy even when PDF layout or fonts are unsupported, plus a separate conservative DOCX preview that leaves malformed fragments literal. Ordinary generation remains strict; production responses retain their limited diagnostic view. See the [inspection guide](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.6/docs/template-diagnostic-pdf.md).

Contract 0.8 adds the optional `DocumentDiagnosticProvider` and immutable source context. Built-in DOCX/PDF providers require 0.8; compatible older provider minima remain accepted. Keep all six libraries aligned. Existing paragraph Java constructors and the Kotlin default-constructor bridge remain binary compatible.

The native engine, standard PDF and independently validated PDF/A-1b/2b/3b, font embedding, requested-watermark profile restrictions, Java 17 libraries and Java 25 service/Playground remain supported within the documented qualified source profile. This does not add ODT, arbitrary drawing effects, PDF/A level A or universal Word compatibility.

## Downloads and evaluation scope

The six alpha libraries are published to [Nexus prereleases](https://repo.nuaforma.dev/repository/nuaforma-prereleases/); stable releases use Maven Central. Production and development Playground images provide native AMD64 and ARM64 variants. Prerelease publication leaves `latest` unchanged.

Dependencies and runtime inputs are unchanged from the reviewed alpha.5 baseline: official Temurin 17.0.21+9 validators, Temurin 25.0.5+8 service/Playground and the pinned 2026-10-30 Debian package snapshot. Matching third-party sources/notices remain publicly available under [sources-v0.3.0-alpha.5](https://github.com/NuaForma/NuaForma/releases/tag/sources-v0.3.0-alpha.5); the signed `v0.3.0-alpha.6` tag supplies the matching NuaForma source. Candidate receipts bind the exact reused source archive identities without downloading them again.

Remaining native-runtime findings, including the separate FreeType copies, stay open under [#51](https://github.com/NuaForma/NuaForma/issues/51). The protected final review must explicitly accept the current findings for this evaluation alpha.6; earlier approvals do not transfer. See the [alpha.6 audit](https://github.com/NuaForma/NuaForma/blob/v0.3.0-alpha.6/docs/release-0.3.0-alpha.6-audit.md). No zero-vulnerability or general production-safety claim is made.
